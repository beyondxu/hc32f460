# 样品机实测参照：VP 15.05V、S低390ns、tFire 1.7us

## 新参照与目标

用户报告样品机使用同一喷头、未再次擦拭/清洗，第二张实际纸面三色均可见（第一张打印错误）。样品机实测VP=15.05V、S低390ns、tFire=1.7us。本机68-NOP候选报告S2=0.445us、tFire=1.95us；后续两张示波器图中S2约450..451ns，D高约459..460ns，能打印的品红与不出黄的被测D脉冲未见明显差异。

样品机三色可见不证明本机选定的S2每个喷嘴都正常，也不证明样品机没有通过之前打印改善喷头状态。当前异常原因仍未确认。

电压基本接近，但本机采样/加热时间偏长。如果本机VP仍约15V，简化V^2*t模型下，本机15^2*1.95与样品机15.05^2*1.7之比约1.14；不是实际能量/温度测量，不作为过热或气泡的定论。

## 本候选改动

沿用独立采样helper，默认TPH_SAMPLING_CHECK_NOPS=57；原68配置可选择，LOCAL_HELPER回退也保留。原用户44-NOP helper及全部列函数、GPIO/LUT、上下电/CE/停止代码不动。只改变独立helper的编译期NOP数量与模式标记；没有每次采样的运行时条件分支。

以200MHz和本机68-NOP/445ns为估计基础，少11个NOP约少55ns，目标S约390ns，tFire约1.95-4*0.055=1.73us。若以截图450ns为基准，则可能约395ns。此推算不保证实际边沿，必须测量；不能声称已经精确复现样品机1.700us。

TPH_SAMPLING_CHECK_NOPS仅支持57或68；默认57，ENABLE默认1。0模式选择原本地helper。若Keil预定义NOPS=68，则仍走旧68，必须看实际启动模式。独立helper以共同57个NOP加编译期可选11个NOP组成，单个asm块，保持memory编译器屏障。

## 先测波形

沿用此前无喷头测逻辑的方法，实际测连接器处四路S的低电平及列内相邻地址同S下降沿间隔，包括末地址到全零停止组。测四路最短值，不能只看函数名、NOP数或CE宽度。

- S1..S4均至少380ns；参考目标约390..400ns。若某路不足380ns，先不带头打印，也不继续删NOP。
- tFire目标靠近样品机1.7us，估计1.7..1.75us；实际数值按测量记录，不把范围当作已认证的15V工作区间。
- 若实测明显不符预期，先回传S/tFire值和启动标记，不继续补打。

测量满足后，保持喷头当前状态、不擦拭，只触发一次12条逐D程序，保存纸面和BK/HC完整日志。数据仍应14160列、1416000字节、CRC A13F47F7、S=02、A=004A2912、D各5688。不要连续反复打印到结果满意。

若黄色仍没有，不能据此排除先前驱动造成的持续状态、喷嘴局部差异或供墨问题；此候选只是向已可出墨样品机的实测时序靠近，不是修复承诺。后续按实测与结果决定进一步对照，避免同时改供电/数据/清洁状态。
