# 固定S2基线：不加1ms，固定A/S/D与每喷嘴指令次数

## 目的与限度

旧版首次APP渲染后只在RAM冻结；重启后图片抖动/位置变化可能把S2换成S1、地址或D位也改变。此版本将一份确定的列数据生成规则固化在BK固件中，APP只作为有效F2触发，图片像素不再决定打印内容；空白但格式有效的原生F2也可触发，损坏/截断BIN仍拒绝。

旧日志仅有CRC和统计，不能恢复原118000字节，也不能仅由地址掩码推出旧图每个A/S/D组合。因此这是新基线，复用其S2地址集合，不声称原图逐字节复原；后续与加间隔版本比较必须继续使用这份相同新基线。

## 固定规则v1

- 每帧1180列，每列100字节。仅S2（slot%4=1），地址LUT索引2/5/9/12/14/18/20/23，地址掩码004A2912。这里是1起算LUT索引，不是A引脚编码。
- 按规格书附录B零起算物理行55..62：D1/D3/D5各用地址23/5/12/18；D2/D4/D6各用14/20/2/9，共24个实际A/S/D组合。
- 六域X补偿列数61/59/31/30/1/0，沿用现有负X、3000列距配置。每个选定喷嘴从其补偿后起点连续711列写1，未选喷嘴/其余列全部为0；没有全头预喷。
- 单喷嘴每帧711个有效指令；一组仍是1/2/1三条，合计2844个有效指令。一次发送自动完成三条，4720列/472000字节；六域各11376个有效位。
- 本次规定的是输入指令数量，不等于测到实际墨滴数量，也不是保证超过1000次就恢复。单次能量取决于用户实测波形。
- 第一有效列150、最后921，全帧772列非零。线的像素形状/长度建立新基线，未修改电机7480步行程、列步距、走纸780/1560步；不要把它与旧图长度直接作缩放校准。

固定校验值（不同APP图、重复触发、重新启动均相同）：

| 项目 | CRC32 |
|---|---|
| 普通单帧 | EA748497 |
| 每列连续发送两次的中间条 | F3FD6745 |
| 三条按1/2/1串接，HC整组接收 | 86CE8D53 |

不是将整个单帧拷贝两遍，而是x0,x0,x1,x1逐列复制。

## 看哪些日志

BK启动必须出现APP_FIXED_S2_BASELINE_V1，触发后出现：

```
[FIXED_S2] v1 A=004A2912 S=02 D=3F frame_crc32=EA748497 ...
[RECOVERY_RX_EXPECT] columns=4720 bytes=472000 crc32=86CE8D53 ...
```

HC上电后必须显示：

```
[TPH COOLDOWN] v1 extra_idle_us=0 ...
```

HC完成后应有：

```
[HC32 RX_AUDIT] bytes=472000 crc32=86CE8D53 D=3F A=004A2912 S=02 dots_D1_D6=11376,11376,11376,11376,11376,11376
```

冷却汇总extra_idle_us=0 columns=0表示没有执行额外等待，不是没有打印；实际打印仍看ROW_AUDIT columns=4720 fired=4720。旧ROW_C/M/Y固定参考位置可能全0，不作为没有三色数据的证据。

## 本轮操作：两组连续，再等10分钟一组

1. 若当前喷头全白，可以仅在开始前擦拭一次，装回后确认能出墨。之后不擦拭、不拆装、不复位。如果第一组已经偏红，只能记录缺色基线，不能声称从三色正常开始；深色线也不能独立证明三色全部正常。
2. 用APP发送一次，等待三条全部完成，再尽快发送第二次，完成另三条。不要在未完成时并发下发。前两组共六条。
3. 第二组全部完成后手工计时约10分钟，保持机器供电，不拔电池、不复位、不发其他打印。组末喷头15V按原程序正常关闭。软件没有新增十分钟自动倒计时。
4. 再发送一次，自动打印三条。总共三次发送、九条；可换纸并清楚标记组1/2/3，不改走纸参数。
5. 回传三组BK/HC完整日志和照片，分别记录首条是否空白、后两条颜色，附停放实际时长。先确认固定CRC/掩码与extra_idle_us=0，再分析纸面。

本轮只建立新固定数据的无额外等待基线。后续加1ms对照继续使用同一BK固定配方，只改变HC额外等待；不在本轮切S分组、不增加预喷、不改变电压或单次波形。不从一组成功就宣称排除气泡或证明过热。

## 验证
