# CE四段均匀小幅缩短：目标实测约2.2us

基线3e7e161（用户实测CE约2.3us），分支codex/printer-ce-trim-balanced。
只更新HC32；BK保持9d445f0上电等待2秒的回程W检查图，不同时换图/速度/电压。
这不是以前已撤回的独立CE实验：CE仍在S1前开启，S4完成后关闭，四段顺序/地址/数据/清零不变。

## 缩短位置

原delay_40ns函数实际含5个NOP；在200MHz、按1周期/NOP估计，仅NOP为25ns，
名字不是实测时长保证。旧每段S上升后各有一次该延时。
本版仅去掉这四处额外NOP空等，每段相同；共20个NOP，名义100ns。
S低电平delay_ts_400ns与每段数据采样前的延时均保持；不是直接把CE末尾截短100ns。
数据一直保持到S上升，后续按volatile GPIO顺序写下一段；原采样后额外软件空等移除。
规格书注释允许前一个S回高后切换D，本改动仍需确认实际D/S保持和总线边沿。
编译器/指令排布/存储器/外设总线会影响实际缩短量，不能把此提交标为已测2.2us。

不同比缩小四个0.4us采样到0.3us，规格书采样下限0.38us必须保留。
首轮只比较约2.3→约2.2us，不直接试1.6/1.8，也不延长脉冲补偿。
本轮按用户及技术人员的调节定义以CE高窗口作为tFire控制量，不以模型代替内部加热测量。
