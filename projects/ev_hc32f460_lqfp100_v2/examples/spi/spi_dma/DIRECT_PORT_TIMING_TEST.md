# DIRECT_PORT_v1：保留S采样，减少地址周期内GPIO写入

用户再次观察到1/2/1首条空白、后两条偏品红。技术支持补充冷态每喷嘴前约1000次可能不好，随后无需擦拭会改善；若每次都需擦拭，可能前端缺墨，并建议有余量时减小能量。这些是候选方向，不是已经确认的根因。

本项不继续加大喷射量，尝试将目前实测约1.8us的tFire小幅缩短，优先约1.7us；不降低共用电源、不动VL，不缩短S低电平。实际周期和S宽度必须以本地编译后测量为准。

## 代码具体变化

当前HC32单核实时打印固件独占相关GPIO输出，没有DMA或其他核写PODRA/PODRB：

- 原每组地址一次清/置，四组数据各一次清/置，合计10次A/D寄存器写；新代码为地址1次PODRB、数据4次PODRA，合计5次。
- GPIO的PODRA/PODRB是输出锁存寄存器，不能用PIDRA/PIDRB输入寄存器代替。LUT译码仍在空闲阶段完成。
- 屏蔽中断之后读取两个输出锁存寄存器，将非数据/非地址位合入预解码的26组。准备时A/D仍处于零空闲状态，不加热。每组均保留CE、VL/VP使能及无关输出状态，然后一次写出，避免全端口写误改其他输出。
- 四个S低脉冲仍使用原delay_ts_400ns，不改共享延时定义。25组打印与第26组Add25全零停止走同一循环；末尾全局清零、恢复PRIMASK、60us空闲保护及上下电流程不变。
- 活动段无源数据读取/查表/计时/函数调用。每组GPIO半字写由旧18次（A/D10+S8）变13次（A/D5+S8）。M4对象已核对。
- 增加TPH_DIRECT_PORT_PAD_NOPS，默认0，只允许0/4/8/12/16。可在S4拉高之后补地址节拍，不插入S低电平，不改变四段采样。它是NOP条数，不是已认证的纳秒数。

此次同时改变A/D的输出方式与地址周期。若改善，不能仅据此宣布“过热已证实”。需要纯周期对照时，可在同一新实现中只调PAD，实测恢复到1.8us再与约1.7us比较，保持输出方式相同。

## 先测再打印

先沿用此前可行的移开喷头测逻辑方法，不用改变测量接法以外的硬件：

1. CE在上电到下电之间持续高，不以CE脉宽当tFire。
2. 四个S低电平实测仍须至少0.38us；“延时函数没改”不能保证编译布局/总线变化后脉宽绝对相同，尤其原来最低已在380ns下限。
3. 测相邻地址同一个S下降沿间隔，特别实际使用的S2。测Add25到全零停止组也是同一节拍。
4. 本轮优先约1.7us。若实测<1.6us，先不要带头打印，可逐档增加PAD重新测；PAD只延长，不能用于缩短。不通过删除S的NOP去追求1.7us。若实测仍>=1.8us，尚未形成减周期对照，应先核对编译结果。
5. 若实测1.75us就记录1.75us，不声称已达到1.70。保持当前同一路电压及S宽度不变。

在V和电阻不变的简化V²t参考下，1.8->1.7us约减5.6%，1.8->1.6us约减11.1%；这不是实测热量，也不是要求本轮直接追到1.6us。

确认时序后，不擦拭、不拆装，用相同1/2/1测试触发一次，观察首/末条和颜色，回传实测tFire/S宽度及两端日志。打印本身仍约30秒，预期4720列/472000字节。若S或周期不满足，上述候选仍未具备带头测试条件；不要用空白打印反推剂量。

## 关于冷态前1000次

1000指每一个喷嘴实际接受的有效喷射，不是1000列、1000次地址循环或某D域合计。原图中只有对应A/S/D位为1时才计入该喷嘴的输入次数，停止和全零采样不计。1/2/1总量为该喷嘴单帧有效点数的4倍，只有D域合计不能得出每个喷嘴都已达到多少次。该冷态经验也不是保证超过1000就全部恢复的固定阈值。

本项不混入新的每喷嘴剂量或更多喷射倍数；先保持同一BK模式做小幅时序候选对照。

## 已做检查与限度

- 实际GPIO/LUT模型：六域、混合/全零/末地址、25+停止组、S采样时A/D稳定、CE连续高、PB5/PB6及其他PA/PB输出保留、两种PRIMASK恢复、空闲计数回绕/失败、上/下电顺序；ASan/UBSan通过。
- M4 -O2/-Os及五档PAD共10份对象：无警告，活动段无函数调用，每组13次GPIO半字写，八个完整S采样NOP块（循环四个+重置四个）保留，栈帧568字节。编译器可插入跳过的文字池对齐NOP，静态计数不作为脉宽。
- 握手、行统计、独立RX CRC检查通过。
- 所有共享延时/LUT/GPIO宏以及此函数之外的驱动代码与7786ad1逐字节一致。函数块可独立交付，无需新Keil编译单元。
- 未完成本地Keil全链接、硬件时序或喷墨验证，不能声称已测到1.7us或已解决偏色。
