# 固定S2、额外1ms间隔：与996/997/998基线比较

## 已完成的无额外等待基线

用户连续打印两组，再停放约12分钟打印第三组，全程不擦拭、不拆装、不复位。BK任务996、997、998均使用固定配方v1，单帧EA748497、逐列x2为F3FD6745、整组86CE8D53；各组4720列/472000字节、A=004A2912、S=02、D=3F、D1..D6各11376位。BK三组结果均code=0；HC全部fired=4720、invalid=0、canceled=0，extra_idle_us=0。

第一组15:44:50.881上电，15:45:16.755关闭；第二组15:45:23.607上电，15:45:49.474关闭；第三组15:57:47.274上电。第二次关闭到第三次开启间隔717.800秒，约11分58秒；这是喷头电源关闭间隔，不冒充最后一次实际墨滴到下一次墨滴的时间。

照片从上到下三条一组：前两组线条较深，第三组首条显著变浅、偏红，后两条较深但仍可见颜色变化。没有整组完全空白；深色不代表已确认全部三色。用户未在本条消息重新提供实测S/tFire或说明开始前是否擦拭，因此不把这些当作本轮已测量/已确认条件。

本轮固定CRC排除了这三组之间APP图片改变、S分组/地址集合更换、接收字节不同作为差异来源；不排除物理GPIO时序、驱动能量、供墨、气泡或喷嘴面状态。短间隔第二组能出墨说明每次正常关闭/重开喷头电源并非必然造成空白；长停放与重启的交互仍未排除。加倍阶段较深不等于自动恢复已成功，需看之后普通剂量那条。

## 本次唯一功能改动

基于HC固定S2基线b8a2d70，仅将tph_column_cooldown.h的默认TPH_COLUMN_COOLDOWN_US从0改为1000。列函数和全部delay_*字节不改，CE常高、25+1停止、全局清零、原60us保护不改，不增加喷射次数。共享头/源文件与本地44-NOP校准无需复制或替换。

等待发生在每列停止清零并恢复PRIMASK之后、READY重装之前。降低平均重复频率并增加回填时间，不降低单次能量；不能单凭改善就认定过热或气泡。之前1ms试验的数据S=01，与本次固定S2不可作为严格对照。

## 重复相同纸面流程

按基线的开始条件操作，记录是否擦拭；若开始前因全白而擦拭，仅在开始前做一次，之后不擦。先打印两组，每组发送一次、等待三条全部结束再发下一组。第二组结束后保持整机通电、不复位，手工停放约12分钟，再发第三组一次。共三次发送、九条，返回完整两端日志与照片。此次选择约12分钟，是为了接近已完成基线的实际11分58秒。

每组额外累计约4.72秒。记录三组首条出墨/颜色及第二、三条；不只根据中间加倍那条深浅判断恢复。若开始前已偏红，按实记录，不声称两轮有相同的三色正常起点；若初始状态不同，因果结论需保留。

如果改善，说明间隔/回填条件有帮助，仍不能区分热积累与气泡/供墨；若恶化或无改善，不继续一味增加等待。后续再根据固定数据结果选择分色或驱动验证，本轮不改变S宽度、tFire、电压或喷射量。

该版本是间隔对照，不解决用户0.29us采样低于现有规格0.38us的适用性问题；相关范围仍需厂商确认。没有实物出墨验证，不承诺恢复。
